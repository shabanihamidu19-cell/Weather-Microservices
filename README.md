# Weather Microservice ☀️🌧️

A Node.js + Express microservice that provides weather data (mock or API integration).  
Designed as a boilerplate for developers building RESTful services.

---

## Features
- `GET /weather` → Returns mock weather data (city, temperature, condition, humidity, wind).
- `GET /health` → Service health status and uptime.
- Jest integration tests.
- Dockerfile for containerized deployment.

---

## Quick Start
```bash
npm install
npm start
